# Mohaned Mohamed Ahmed Portfolio

An English-language portfolio for Mohaned Mohamed Ahmed, built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. The site has no build step or package dependencies.

## Publish with GitHub Pages

The site is ready to publish from the repository root. In the repository settings, enable GitHub Pages for the `main` branch and `/ (root)`.

## Files

- `index.html` contains the portfolio content and layout.
- `styles.css` contains the responsive styling and animations.
- `script.js` contains the navigation, scroll effects, and interactions.
- `mohaned-street.jpeg` and `mohaned-portrait.jpeg` are the portrait photos used in the hero.
- `Mohaned_Mohamed_CV.docx` is linked from the page as a downloadable CV.
